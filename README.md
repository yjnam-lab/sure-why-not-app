# Sure Why Not

> **An accessible navigation and object recognition mobile app built to support visually impaired individuals in retail environments.**
🔒 *Notice: The source code for this project is stored privately for archiving and maintenance purposes. This README presents a high-level overview of the project's features and technical stack.*

---

## 📌 Project Overview

**Sure Why Not** is an Android-based accessibility solution designed to enhance independent mobility and item identification for visually impaired users.

* **Proximity Sensing**: Integrates short-range wireless communication to deliver location-aware audio cues.
* **Computer Vision Processing**: Employs image recognition technology to identify physical objects and convey real-time feedback to users.

---

## 🛠️ Tech Stack

* **Platform**: Android
* **Hardware & Wireless**: Bluetooth Low Energy (BLE) / Beacon, NFC
* **AI & Vision**: Google Cloud Vision API

---

## 🚀 Key Technical Highlights

* **Location & Proximity Services**: Handled short-range signals (Beacon/NFC) to trigger contextual notifications.
* **Image Recognition Integration**: Utilized cloud-based vision APIs to process visual inputs and transform them into auditory information.
* **Accessibility-Oriented UI/UX**: Designed a voice-first user interface structured around screen readers and accessibility guidelines.
